PROFESOR ABELTON (Windows) — Quick Start
Version: 2.0.0

Ovo je PORTABLE aplikacija (bez klasične instalacije).

1) Kako pokrenuti
----------------
1. Raspakiraj cijeli ZIP (nemoj pokretati iz ZIP-a).
2. Otvori folder: ProfesorAbelton\
3. Pokreni: ProfesorAbelton.exe

VAŽNO:
- Ne briši i ne miči folder "_internal" niti ostale fajlove uz .exe.
- .exe mora ostati u istom folderu s ostatkom bundle-a.

2) Ableton setup (Control Surface)
----------------------------------
Da Ableton vidi kontrolnu skriptu:
1. Pokreni ProfesorAbelton.exe (Wizard će pomoći pri prvom pokretanju).
2. Restartaj Ableton Live.
3. Ableton Preferences → Link/Tempo/MIDI:
   - Control Surface: ProfesorAbelton
   - Input/Output: None

Ako želiš ručno:
- Script se nalazi u ovom paketu pod: RemoteScript\
- Odredišna lokacija (Windows, tipično):
  %APPDATA%\Ableton\Live XX\Preferences\User Remote Scripts\ProfesorAbelton\

3) API ključevi
--------------
U GUI-u: Settings → API Keys
- Dostupno u UI: GROQ + CLAUDE (MCP)

4) Tray ponašanje
-----------------
- Prozor je u taskbaru kao normalna aplikacija.
- Tray se koristi samo kad klikneš HIDE ili zatvoriš prozor (X), ako je tray podrška dostupna.
