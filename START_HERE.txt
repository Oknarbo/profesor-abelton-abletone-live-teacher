⚡ BRZO TESTIRANJE / QUICK TEST:

Nakon instalacije / After installation:

1. Otvori Command Prompt / Open Command Prompt
2. Upiši / Type:
   
   python --version
   
3. Trebao bi vidjeti / You should see:
   
   Python 3.x.x

4. Ako ne vidiš / If not:
   → Reinstaliraj Python / Reinstall Python
   → Označi "Add to PATH" / Check "Add to PATH"

❓ PROBLEMI? / ISSUES?

Server se ne pokreće / Server won't start:
→ Provjeri Python / Check Python
→ Pokreni install.bat ponovno / Run install.bat again

Ableton ne vidi script / Ableton doesn't see script:
→ Restartuj Ableton / Restart Ableton
→ Provjeri Preferences / Check Preferences

Voice ne radi / Voice doesn't work:
→ pip install pyaudio
→ Provjeri mikrofon / Check microphone
