## Profesor Abelton — Clean Workspace

Ovaj folder je “clean” snapshot samo onoga što je relevantno za trenutnu verziju Profesor Abelton.

### Kanonska imena
- **Product name**: Profesor Abelton
- **Ableton Control Surface / Remote Script name**: ProfesorAbelton

### Što je unutra
- `GUI/` — GUI + wizard
- `Server/` — socket server + LLM integration
- `RemoteScript/` — Ableton Remote Script (Python 2.7 kompatibilno)
- `Utils/` — detekcija/install helperi + API key manager
- `Config/` — `copilot_config.json` (default UI: GROQ + CLAUDE)
- `Docs/` — dokumentacija
- `SOURCE OF TRUTH.md` — obavezno čitati prije promjena

### Što namjerno nije kopirano
- `dist/`, `build/`, `.spec`, `.toc`, stare instalacije i ostaci prethodnih verzija.
