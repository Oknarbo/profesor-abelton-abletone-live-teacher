# Profesor Abelton — Landing (local test)

Ovo je statičan landing page (HTML/CSS/JS) s placeholder tekstovima.

## Lokalno testiranje

### Opcija A — samo otvori file
- Otvori `website/index.html` u browseru.

### Opcija B — lokalni web server (preporučeno)
U rootu projekta:

**PowerShell (Windows):**
```powershell
cd "C:\Users\L450\Downloads\sol sniper bot\PROFESOR_ABELTON_CLEAN\website"
python -m http.server 8000
```

Zatim otvori u browseru:
- `http://localhost:8000`
